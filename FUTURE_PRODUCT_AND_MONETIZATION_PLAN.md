## 1. Executive Product Strategy

Files Sandbox is transitioning from a free utility site into a commercial, privacy-first **SaaS Product ("Files Sandbox Pro")**. 

The core value proposition remains **100% Stateless RAM File Processing** (zero server disk storage, privacy guaranteed), paired with high-speed algorithms (sub-0.02s PDF target compression, visual E-signatures, CSV data cleaning, and Text-to-PDF document generation).

To monetize effectively without alienating new users, we deploy a **Freemium Daily Meter + ₹299/year Pro Membership Pass**.

## 3. Product Features & User Experience Improvements

To make Files Sandbox a premium, high-converting product, we will implement the following features:

### A. Live Usage Meter Badge (Navbar)
- A clean, monospace badge in the top navigation bar showing remaining free daily operations:
  - `3 / 5 free daily uses left`
- When the 5-operation limit is reached, a smooth, non-disruptive **Upgrade Modal** pops up explaining the ₹299/year Pro Pass.

### B. Integrated Razorpay Checkout Modal
- 1-click **"Upgrade to Pro — ₹299/yr"** button triggering the Razorpay checkout widget.
- Supports UPI (GPay, PhonePe, Paytm), Credit/Debit Cards, NetBanking, and Wallets.

### C. Zero-Friction License Key & Email Activation
- Upon successful payment via Razorpay, a **Pro Pass License Key** is issued to the user's email and stored in their browser `localStorage`.
- No password or complex login required; 100% friction-free access.

### D. Mandatory Razorpay KYC Legal Pages
To ensure 100% Razorpay merchant account activation, the website footer will include:
1. **Terms & Conditions**: Standard SaaS software usage terms.
2. **Privacy Policy**: Explicit zero-retention in-memory data processing statement.
3. **Refund & Cancellation Policy**: 7-day money-back guarantee policy.
4. **Contact Us Page**: Working support email (`support@sagarthalavar.in`) and contact form.
