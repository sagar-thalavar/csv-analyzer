## 2. Technical Assets & Proprietary IP Included in Sale

A buyer acquiring Files Sandbox receives 100% intellectual property ownership of:

### A. Core Software Engines
- **Sub-0.02s Binary Search Auto-Target Compression Engine**: Proprietary 3-pass algorithm reducing file sizes to exact KB targets.
- **Visual E-Signature Suite**: Multi-ink draw pad, handwriting font generator, PNG upload, live webcam signature capture, and token positioning math.
- **Stateless PDF Page Organizer**: Split, merge, rotate, delete, crop margins, and stamp dynamic page numbers in memory.
- **Bidirectional PDF & Data Converters**: PDF to Word (`.docx`), Excel (`.xlsx`), Text, HTML, and Images, plus Images/Text/Word to PDF.
- **Stateless CSV Profiler & Data Cleaner**: Automated missing row dropping, mean/median filling, duplicate removal, outlier detection, and Matplotlib charting.
- **AI Text-to-PDF Studio**: ReportLab Flowables compiler converting text outlines into styled PDFs (<1s).

### B. Infrastructure & Codebase Quality
- **Dual Architecture Support**:
  1. **Flask + Pure HTML/JS** (Currently deployed live on Vercel at `files.sagarthalavar.in`).
  2. **Vite + React SPA** (Isolated on `migration_react` branch for modern frontend expansion).
- **Zero Disk Footprint**: 100% in-memory streaming (`io.BytesIO()`) preventing file storage liabilities, disk cleanup cron jobs, or GDPR/HIPAA leak risks.
- **Serverless Vercel Deployment**: Deployable in 1 click with $0 fixed hosting costs.
